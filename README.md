# Snake-in-CSFML

Controls:
Hold Click to speed up.
Space to pause.
Escape to exit

Decomp:
A decompilation was done in collaboration with [Linkz](https://github.com/Linkz64) as a Reverse Engineering challenge. Ghidra 11.1.1 was used for the decomp, and the source was rewritten in Odin. The final code ended up functionally accurate, ofcourse variable names dont match, but the logic is there.
